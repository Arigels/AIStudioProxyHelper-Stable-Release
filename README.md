# AI Studio 反代助手（正式版 1.0）

> 把手机变成一台随身 Gemini 反代服务器：在 Android 上联动 Termux，完成 Google AI Studio 反代服务的部署、启动、账号导入、额度监控和酒馆连接。

本项目是 [DeconstructedCube/aistudio-api](https://github.com/DeconstructedCube/aistudio-api) 的 Android 图形化封装。它不修改上游协议，只把原本零散的教程步骤、工具下载、网页跳转等集成到App和悬浮窗中。

**当前版本：1.0（versionCode 68）**  
**适用平台：Android 8.0 及以上，arm64 手机**

---

## 它是怎么工作的

- App 本身不是反代服务器。真正的反代服务运行在 **Termux** 里。
- App 通过 Termux 的 `RUN_COMMAND` 和无障碍服务下发送安装、启动、停止、改端口等命令。
- App 轮询本机反代接口，把服务状态、账号数、模型数、额度和错误显示在界面与悬浮窗里。
- 部署完成、Cookie 导入后，**App 可以直接关闭**；只要 Termux 和 VPN 还在后台运行，反代就继续工作。

> 反代走的是 Google AI Studio 的网页登录态（Cookie），并非Gemini 官方 API Key。

## 三个页签

App 有 **3 个页签**：**反代 / 账号 / 解疑**。App 默认打开「反代」页。

### 1. 反代

这是部署和运行的主页面，围绕「把服务跑起来」这一件事。

- **服务状态卡**：显示反代是否在线、签名引擎是否运行、已导入账号数、可用模型数。
- **地址区**：显示本机代理地址，支持一键复制地址、复制 `/v1beta` 地址、在浏览器打开管理面板。
- **半自动部署**：首次使用点「半自动部署反代」，App 会先提醒开 VPN，再复制部署命令并引导进入 Termux 粘贴执行。
  - 已开启无障碍时，App 可以自动打开 Termux、自动粘贴并执行，尽量少让用户手动操作。
  - 无障碍不可用时，自动降级为「复制命令 + 弹窗教你怎么粘贴」。
  - 部署过程显示已用时、当前阶段（安装依赖 → 克隆仓库 → 编译签名引擎 → 启动），超过 20 分钟会提示可能失败。
- **日常维护**（测试功能，未经测试，谨慎使用）：服务运行中显示「停止反代服务」；已经部署过但服务掉线时，会单独出现「重启反代」卡片；需要更新上游或修复环境时，使用「更新并重新编译修复」。
- **首次准备**：内置 Termux 下载入口（F-Droid / GitHub）、悬浮窗授权入口、无障碍可选授权入口。
- **高级设置**（测试功能，未经测试，谨慎使用；默认折叠）：
  - 端口，默认 `8080`，可用范围 `1024~65535`
  - 网络代理，例如 `http://127.0.0.1:7890`，留空自动探测
  - 管理后台密码
  - 安装目录
  - 安全密钥：API 访问密钥 + 管理后台密码
  - 授予 Termux 后台静默调用权限
  - 设置 Termux 电池无限制
  - 开启唤醒锁
  - 复制手动安装命令（备用）
- **公共网络安全提醒**：反代默认监听 `0.0.0.0:端口`，同网段设备可以访问。App 会常驻安全提醒，并在检测到公共/企业网络时弹窗，建议设置 API 访问密钥和管理密码，或直接关闭反代改用手机流量。

### 2. 账号

这是 Cookie、账号和额度管理中心。

- **实时额度检测**：不用跳转管理台，直接查看今日调用次数、今日 Token、可用账号、当前激活账号、每日配额剩余和重置倒计时。
- **账号操作**：支持启用/停用、切换下一账号、探测账号等级与邮箱、删除账号。
- **单账号明细**：展开后可以看到该账号可用模型、今日调用、Token 消耗、429 冷却、每日配额进度。
- **每日额度对照表**：按账号等级展示每日次数/Token 规则，包含单模型精确覆盖和模型订阅准入说明。
- **Cookie 教程**：内置 5 步教程，自动检测手机是否装了 Edge 或火狐，并给出对应入口：
  1. 安装支持扩展的浏览器（Edge / 火狐）
  2. 安装 Cookie-Editor
  3. 登录 Google AI Studio，进入 Playground
  4. 用 Cookie-Editor 导出 JSON
  5. 回到 App 导入
- **两种导入方式**：
  - 「粘贴剪贴板」：直接读系统剪贴板，绕过部分输入法的字数上限。
  - 「从文件导入」：读取 `.json` / `.txt` 文件，适合大 Cookie 或从电脑导出。
- **自动识别多账号**：一个 Cookie JSON 可以自动识别 `u/0`、`u/1` 等已登录子账号。
- **导入前预检**：会提示“像链接不像 Cookie”“游客 Cookie”“缺少 `.google.com` 的 SAPISID”“域名不对”等常见问题，减少导入后才发现 401/403。

> 导入 Cookie 前需要先启动反代服务。服务没启动时，账号页会直接提示。

### 3. 解疑

这是教程、报错解释和 AI 排障的集中页。

页面顶部有常驻黄色提示：

> 报错翻译和 AI 排障助手为测试功能，未经完整测试，谨慎使用。
>
> 解疑页部分教程由 AI 生成，内容不一定准确。此前优化重点放在反代部署和 App 使用上，这部分教程尚未逐条校对修改，后续会继续更正、润色。

包含：

- **报错翻译器**（测试功能，未经测试，谨慎使用）：把 Termux 里的报错粘贴进来，点「帮我看看」，用大白话解释原因和修复方向。Termux 的普通报错通常就是白色普通文本，直接复制你看到的那段即可。覆盖端口权限、端口占用、网络下载失败、403/429、内存不足等常见问题。
- **AI 排障助手**（测试功能，未经测试，谨慎使用；默认折叠，点开才展开）：
  - 来源一：**本地反代**。直接调用你自己搭的反代模型，不需要填地址和 Key；反代服务必须先启动。
  - 来源二：**自定义（外接模型）**。支持 `Gemini（官方 Key）` 和自定义 OpenAI 兼容地址，填入地址、API Key、模型后使用。
  - 两种模式：**搭建排障** 和 **酒馆问答**。
  - AI 使用 App 提供的受限工具：`get_status` 查状态、`get_log` 读日志、`run` 执行命令、`install` 重新安装、`start`/`stop` 启停服务、`set_port` 改端口、`wait` 等待、`finish` 给结论。
  - 每一步「判断 / 执行 / 结果」都在界面上可见；明确禁止删除用户数据、`rm -rf`、格式化、修改系统设置等危险操作。
  - 支持「从零开始，让 AI 自动搭建」和常见问题快捷提问。
- **Termux 多开窗口教程**：教你在 Termux 里再开一个会话跑酒馆，反代和酒馆各占一个窗口。
- **连接客户端（酒馆）**：复制本机地址，按步骤填入酒馆。
- **无障碍详细教程**：按机型给出无障碍设置路径，解决“已限制设置”“服务没连上”等问题。
- **常见问题**：模型列表为空、403/429、App 能不能关、Termux 没装、服务掉线等。

配套的日志回传：Termux 里安装/执行命令的输出会通过 `127.0.0.1:8099` 送回 App，AI 排障助手和报错翻译器都能读到。

## 悬浮窗：7 步向导

在「反代」页开启悬浮窗权限后，Termux 或酒馆上方会出现一个可拖动的小窗。它不是单纯的状态胶囊，而是一套 7 步向导：

1. **部署**：检查 Termux、确认 VPN、开始半自动部署，显示实时阶段和错误。
2. **浏览器**：引导安装 Edge 或火狐。
3. **扩展**：引导安装 Cookie-Editor。
4. **AI Studio + Cookie**：打开 AI Studio、登录、进入 Playground、用 Cookie-Editor 导出 JSON。
5. **粘贴**：一键打开 App 并读取剪贴板，导入 Cookie。
6. **Termux 双窗口**：引导在新会话启动酒馆。
7. **复制地址并完成**：复制本机地址、填入酒馆，点「完成」后教程永久不再出现。

其他能力：

- 常驻显示本机地址，点地址即可复制，并弹出「已复制地址」提示。
- 支持收起成长条：`反代：端口  地址  −  ×`。
- 「🩺 报错」（测试功能，未经测试，谨慎使用）会读取后台日志和当前屏幕文字（需无障碍），调用 AI 分析后在悬浮窗内放大显示，可上下滚动。
- 服务掉线时显示「反代断线了」，提供「启动反代 / 诊断」。
- 频繁掉线时会提示把 Termux 拉成小窗/分屏、关闭电池优化。

## 快速开始

1. **安装 Termux**  
   从 [F-Droid](https://f-droid.org/packages/com.termux/) 或 [GitHub Releases](https://github.com/termux/termux-app/releases) 下载 **arm64-v8a** 版本。不要用 Google Play 商店的旧版。

2. **准备网络**  
   打开 VPN，确认手机能正常访问 Google。部署和运行反代都需要它，装好之后也不要关。

3. **安装并授权 App**  
   安装 AI Studio 反代助手。建议授予「显示在其他应用上层」；无障碍是可选项，开了可以让悬浮窗读取屏幕报错，也能让部署自动粘贴。

4. **部署反代**  
   打开「反代」页 → 点「半自动部署反代」→ 确认 VPN → 按提示进入 Termux 粘贴命令并回车。  
   首次部署通常需要 **5~15 分钟**，编译签名引擎时长时间没有输出属于正常现象。

5. **导入账号**  
   服务状态变绿后，去「账号」页，按内置教程用 Edge/火狐 + Cookie-Editor 导出 JSON，再点「粘贴剪贴板」或「从文件导入」。  
   导入成功后会自动识别账号，并刷出可用模型与额度。

6. **连接酒馆**  
   在「反代」页或悬浮窗复制本机地址，打开酒馆配置。

## 酒馆（SillyTavern）配置

1. 打开酒馆，点左上角插头图标。
2. API 类型选择 **Chat Completion**。
3. 聊天补全来源选择 **Google AI Studio**。
4. 反向代理地址填 App 复制的本机地址。
5. 代理密码：
   - 如果 App 里设置了 API 访问密钥，填那个密钥；
   - 如果没设置，随便填一个非空值即可。
6. 连接后拉取模型列表并选择模型。

> 协议必须选 Google Gemini / Google AI Studio。本项目没有 `/v1/chat/completions`，不要选 OpenAI 格式。

## 后台保活与恢复

- 下拉 Termux 通知，点 `Acquire Wakelock`。
- 系统电池设置里把 Termux 设为「无限制」，避免被厂商杀后台。
- App 里也提供「设置 Termux 电池无限制」和「开启唤醒锁」按钮。
- 手机重启或服务掉线后，打开 App →「反代」页点「重启反代」即可，不需要重新安装。
- App 本身可以不挂后台；反代跑在 Termux 里，保持 Termux 和 VPN 在后台即可。

## 常见问题

**Q：模型列表是空的？**  
先确认反代服务在线，再去「账号」页重新导入 Cookie；Cookie 过期、账号被风控或 VPN 不通都会导致空列表。

**Q：客户端报 403？**  
多数是 Cookie 失效、账号被风控，或 VPN 节点被 Google 拦截。重新导出并导入 Cookie，换一个干净节点再试。

**Q：报 429？**  
账号额度用完或触发限流。系统会按模型冷却并自动切换账号；也可以等冷却结束、切换下一账号或导入更多备用账号。每日配额按美西 00:00（PST）重置。

**Q：App 可以关掉吗？**  
可以。反代服务实际运行在 Termux 里，App 只是部署和管理工具。部署、导入账号完成后可以直接划掉 App，只要 Termux 和 VPN 在后台运行。

**Q：Cookie 粘贴被截断？**  
不要点进输入框用输入法剪贴板粘贴。用「粘贴剪贴板」按钮，或把 JSON 存成文件后用「从文件导入」。

**Q：Termux 检测不到？**  
确认安装的是 F-Droid / GitHub 的 arm64 版本，不是 Google Play 旧版；安装后先打开一次 Termux，再回 App 刷新状态。

**Q：没有 Gemini 官方 API Key 能用吗？**  
可以。反代主链路用的是 AI Studio Cookie，不需要官方 API Key。官方 Key 只用于「AI 排障助手 → 自定义（外接模型）」这条可选路径。

**Q：手机版 Chrome 行不行？**  
不行。Chrome 安卓版不支持浏览器扩展；请用 Microsoft Edge 或火狐国际版。

## 从源码构建

仓库已带 GitHub Actions 工作流，推送到 `main` 后会自动构建 APK：

1. 把源码推送到 GitHub 仓库的 `main` 分支。
2. 打开仓库 **Actions** → `Build Android APK`。
3. 等待工作流完成。
4. 在运行记录的 **Artifacts** 中下载 APK，传到安卓手机安装。

本地构建：用 Android Studio 打开项目，执行 `Build → Build APK(s)`。

## 安全与隐私

- Cookie、API Key、管理密码只保存在本机，请不要把包含这些内容的截图、日志或配置文件发到公开仓库。
- 反代默认监听 `0.0.0.0`，同一 Wi-Fi 下的设备可以访问。**不要在公共 Wi-Fi、公司网络、校园网直接裸奔使用**。
- 建议同时设置：
  - **API 访问密钥**：客户端调用 `/v1beta` 时必须携带；
  - **管理后台密码**：保护网页管理面板。
- App 会在检测到公共/企业网络时弹窗提醒，可一键设置密钥，或立即关闭反代。
- 使用外部 AI 模型排障时，App 会把排障所需的状态、日志或屏幕文字发送到你填写的接口；使用「本地反代」模式则不经过外部接口。
